
# Object-Oriented Programming 1 (OOP1)

Course assignments and projects developed using Java, focusing on object-oriented programming concepts.

## Projects

### Plant Guide System

A Java-based application designed to help users discover plants, learn how to care for them, explore plant categories, and share tips. The system also allows users to submit corrections to plant information and explore the symbolic meanings of plants.

## Main Features

- Plant search and plant care guidance
- Plant categorization
- User tips and comments
- Information correction system
- Admin management
- Plant symbolic meanings

## Technologies

- Java
- Object-Oriented Programming
- UML Class Diagrams
- Inheritance
